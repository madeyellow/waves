## 💾 Installation

WAVES requires [Event Bus](https://github.com/madeyellow/event-bus). Open `Packages/manifest.json` and add both packages to `dependencies`:

```json
"com.madeyellow.event-bus": "https://github.com/madeyellow/event-bus.git",
"com.madeyellow.waves": "https://github.com/madeyellow/waves.git"
```

Return to Unity and wait until Package Manager finishes resolving.
